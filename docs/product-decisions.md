# Product Decisions

- Keep Vite, Express, Drizzle, and PostgreSQL; a framework migration has no V1 value.
- V1 starts with diagnosis, projects, a seven-day sales-experiment sprint, community, radar, vault, manual payments, and basic admin controls.
- Manual payment claims require human verification. Access is granted only in the verification transaction.
- AI assistant, email delivery, DMs, payment gateways, and native apps are not V1 capabilities.
- No testimonials, user counts, claimed outcomes, or fabricated payment/analytics data.
- The core product task is an evidence-backed next action, not passive content consumption.
