# Product Roadmap

## V1

Diagnosis, account onboarding, projects, seven-day experiment sprint, evidence tracking, community, radar, vault, manual payment claims, and basic admin review. Launch only after the release checklist is complete.

## V1.1

Prioritize improvements from observed funnel completion, actual buyer conversations, support needs, and payment review experience.

## V2

Build only features supported by production behavior. Do not build future features from assumptions alone.
